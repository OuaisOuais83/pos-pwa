# POS Nightclub PWA

Application PWA Vue.js + TailwindCSS pour gérer le point de vente d'une boîte de nuit.

## Structure du projet

Voir le dossier `src/` et `public/` pour l'ensemble des fichiers.

## Prérequis

- Node.js v16 ou supérieur
- npm ou yarn

## Installation

```bash
git clone https://github.com/TonNomUtilisateur/pos-pwa.git
cd pos-pwa
npm install
```

## Développement (pré-prod en direct)

```bash
npm run dev -- --host
```

Ouvrir l'URL Network affichée sur terminal depuis un mobile.

## Build et pré-production statique

```bash
npm run build
npm run preview
```
